DESIGN SYSTEM CHECKLIST
=======================

SPACING
- All spacing between elements is consistent
- Internal padding in sections is consistent
- Spacing between sections is consistent
- No elements feel cramped or overly spaced

TYPOGRAPHY
- All section titles use the same size
- All labels use the same size
- All values use the same size
- No text smaller than 10px or larger than 20px (except main title)

COLORS
- Background colors are consistent
- Text colors are consistent (primary/secondary)
- Accent colors per section are used consistently
- Sufficient contrast for readability

COMPONENTS
- All sliders have consistent sizes (vertical/horizontal/knob)
- All ComboBoxes have consistent sizes
- All buttons share a consistent height
- Border radii are consistent

LAYOUT
- Elements align to a reasonable grid
- Sections in the same row share equal width
- No overflow occurs
- Vertical scrolling works correctly

RESPONSIVE
- Looks good at 1024x700
- Looks good at 1920x1080
- No layout breakage when shrinking the window
